## 这是什么

PrivateTube 是面向 **Android TV 和 Google TV** 的 PornHub 原生客户端，使用 Kotlin 编写（Jetpack Compose for TV、Media3）。

它既不是浏览器，也不是套壳网页：这里没有 WebView。由用户的设备自行请求网站的公开页面，应用从中提取标题、预览图和视频流链接，并在专为普通遥控器设计的自有界面中显示。

## 为什么做这个

在电视上使用网站很不方便：元素细小，界面是为鼠标和触摸屏设计的，还有弹窗。电视需要自己的界面：大卡片、清晰的焦点、快速的响应和遥控器操作。

## 借助 AI，几个晚上完成

PrivateTube **是在 AI 的帮助下，只用几个晚上做出来的**。由人提出任务、检查结果并指出需要返工的地方；AI 负责编写代码、分析页面结构、准备测试和修复错误。

**我的看法：PornHub 的开发者完全可以做出这样一款官方客户端。** 以我的经验，这件事做起来快、并不难，也不需要花费数千美元的开发成本。对他们来说甚至更简单：他们可以直接访问自己的数据，无需解析自家网页。当然，官方产品需要持续支持，也需要在不同设备上测试，但做一款好用的电视客户端完全是力所能及的事。

如果官方应用问世、本项目不再被需要，用户只会感到高兴。

## 功能

- 首页提供无尽的内容流，侧边菜单包含分类、频道、模特和搜索。
- 大卡片、列表自动加载、完全支持遥控器操作，无需横向滚动。
- 自带播放器（HLS）：可选画质，按 30 秒快进快退（长按按钮时加速），可从保存的位置继续观看。
- 长按视频打开菜单：继续播放或从头开始、收藏、订阅上传者、查看其其他视频。
- 本地的“订阅”“收藏”和“历史记录”栏目。
- 在本地导出和导入收藏、订阅与历史记录。
- 进入应用时的 PIN 码。
- 13 种界面语言：英语、俄语、乌克兰语、西班牙语、葡萄牙语（巴西）、法语、德语、意大利语、波兰语、荷兰语、捷克语、日语和简体中文。语言可跟随系统，也可在设置中选择。
- 视频标题取自同一语言版本的网站。网站并未翻译所有标题，日语和中文的已翻译视频明显较少。
- 在 720p、1080p 和 4K 屏幕上缩放一致，提供两种字号：中和大。

## 如果网站打不开：VPN

**如果网站在你所在的国家或被你的网络服务商屏蔽，或者视频无法加载，请在电视、电视盒子或路由器上开启 VPN。**

请先确认使用 VPN 和访问此类内容**在你所在地是合法的**。某些国家对此有限制。遵守当地法律是用户的义务。本项目不提供 VPN，与任何 VPN 服务均无关联，也不推荐具体服务。

## 隐私

- 应用不需要任何账号：既不需要 Google 账号，也不需要网站账号。
- 应用中没有 Google 服务，也没有自带的分析工具和统计计数器。本项目没有自己的服务器，作者不会收到任何数据。
- 视频和网站页面不会保存到磁盘。视频预览图在退出应用时删除，并在下次启动时再次删除。分类、频道、模特和上传者的图片会保留在缓存中（最多 60 MB），直到被新图片替换，或你在设置中清除缓存。
- 收藏、订阅、历史记录和播放位置仅保存在设备上。
- PIN 码以盐值和哈希的形式保存。它能防止他人随手使用，但无法阻止对设备拥有完全访问权限的人。

**不存在百分之百的匿名。** 网站、你的网络服务商、网络管理员和 VPN 服务仍可能在其技术能力范围内看到有关你连接的信息。网站按照自己的规则处理请求。

### 备份

- 导出会在“下载”文件夹中生成类似 `user_preferences_26_11_2026_02_49.dat` 的文件。
- 其中包含收藏、订阅、观看历史和视频播放位置。PIN 码和应用设置不在备份中。
- 备份内容经过压缩和加密，因此无法用文本编辑器读取。但密钥内置于应用中，在源代码里可以看到。
- 导入只补充缺少的内容，不删除任何数据。历史记录最多保存 100 条。
- 清除缓存或卸载应用时，该文件不会消失。如果不再需要，请自行删除。

## 安装

需要 Android 7.0 或更新版本。

1. 从本仓库的 **Releases** 部分下载 APK。
2. 用你方便的方式把 APK 传到电视上，例如用手机上的 LocalSend 应用，或在电脑上通过 SAMBA 传输；先允许安装来自未知来源的应用，然后安装。

也可以通过 ADB 安装（手机上使用 atvTools，或电脑上使用 ADB App Control）。

请只安装本仓库提供的 APK 或你自己构建的 APK：作者不对他人的构建版本负责。

## 从源代码构建

需要 JDK 17 或更新版本，以及 Android SDK（compileSdk 36）。SDK 路径在 `local.properties` 或环境变量 `ANDROID_HOME` 中设置。

```bash
./gradlew testDebugUnitTest
./gradlew assembleRelease
```

在 Windows 上使用 `.\gradlew.bat`。生成的文件是 `app/build/outputs/apk/release/app-release.apk`。

如不另行配置，发布版本会使用你电脑的**调试密钥**签名。若要分发，请创建自己的密钥（`keytool`），并在旁边放置 `keystore.properties` 文件：

```properties
storeFile=release.p12
storePassword=你的密码
keyAlias=你的别名
keyPassword=你的密码
```

`storeFile` 中的路径以该文件所在文件夹为基准。`keystore.properties` 本身的路径请写在 `local.properties`（`privatetube.signing=...`）或环境变量 `PRIVATETUBE_SIGNING` 中。请将密钥保存在仓库之外并做好备份。签名不同的 APK 无法覆盖安装旧版本：删除旧版本前请先导出数据。

## 代码结构

| `app/src/main/java/com/privatetube/app/` 中的文件夹 | 内容 |
|---|---|
| `core/network` | 对网站的请求、网址和 User-Agent |
| `core/parsing` | 页面解析；选择器集中在 `ParsingRules.kt` 中 |
| `data` | 数据仓库、本地存储、缓存、备份 |
| `domain` | 数据模型 |
| `feature` | 各个界面 |
| `ui` | 通用组件、焦点、图片加载 |

如果网站更改页面结构，大多数情况下只需修改 `core/parsing`。`app/src/test/resources/fixtures/` 中的测试页面已做匿名处理。针对真实网站的检查（`LiveSiteCheck`）只能设置变量 `TV_LIVE=1` 后手动运行。

## 已知限制

- 应用依赖网站的页面结构和规则，**随时可能无法使用**。
- 不支持登录网站账号。订阅和收藏仅保存在本地，不与网站同步；没有新视频通知。
- 不能播放付费内容。
- 部分视频在你所在的地区可能无法观看。网站可能限制请求频率。
- 各语言译文未经母语者审校。
- 开发过程中，应用通过自动测试和模拟器（屏幕为 1080p 的手机版 Android 镜像）进行了检查。不保证在特定型号的电视和电视盒子上正常运行。
