## これは何か

PrivateTubeは、**Android TVとGoogle TV**向けのPornHubのネイティブクライアントです。Kotlin（Jetpack Compose for TV、Media3）で書かれています。

ブラウザでも、サイトを「包んだ」だけのものでもありません。WebViewは使っていません。利用者の端末がサイトの公開ページを自分で取得し、アプリがそこからタイトル、サムネイル、ストリームのリンクを取り出して、普通のリモコン向けに作った独自の画面に表示します。

## なぜ作ったのか

テレビでサイトを使うのは不便です。要素が小さく、画面はマウスとタッチ操作向けで、ポップアップも出ます。テレビには専用の画面が必要です。大きなカード、わかりやすい選択表示、素早い反応、そしてリモコン操作です。

## AIの助けを借りて数晩で完成

PrivateTubeは、**AIの助けを借りて文字どおり数晩で**作られました。人が課題を出し、結果を確認し、直すところを指示しました。AIはコードを書き、ページの構造を解析し、テストを用意して不具合を直しました。

**私の意見：PornHubの制作者なら、このような公式クライアントを十分に作れるはずです。** 私の経験では、短期間ででき、難しくもなく、何千ドルもの開発費はかかりません。彼らにとってはさらに簡単でしょう。自社のデータに直接アクセスでき、自分たちのウェブページを解析する必要もないからです。もちろん公式の製品にはサポートやさまざまな端末での確認が必要ですが、使いやすいテレビ向けクライアントは十分に実現できる課題です。

公式アプリが登場してこのプロジェクトが不要になれば、利用者は喜ぶだけです。

## 機能

- 終わりのないおすすめ一覧があるホーム画面と、カテゴリ、チャンネル、モデル、検索を備えたサイドメニュー。
- 大きなカード、一覧の自動追加読み込み、横スクロールなしのリモコン完全対応。
- 独自のプレーヤー（HLS）：画質の選択、30秒単位の早送り・巻き戻し（ボタン長押しで高速）、保存した位置からの続き再生。
- 動画の長押しメニュー：続きから再生または最初から再生、お気に入り、投稿者の登録、その投稿者のほかの動画。
- 端末内の「登録チャンネル」「お気に入り」「履歴」。
- お気に入り、登録チャンネル、履歴の端末内エクスポートとインポート。
- 起動時のPINコード。
- 表示言語は13種類：英語、ロシア語、ウクライナ語、スペイン語、ポルトガル語（ブラジル）、フランス語、ドイツ語、イタリア語、ポーランド語、オランダ語、チェコ語、日本語、中国語（簡体字）。言語はシステムに合わせるか、設定で選びます。
- 動画のタイトルは同じ言語版のサイトから取得します。サイトはすべてのタイトルを翻訳しているわけではなく、日本語と中国語では翻訳された動画がかなり少なめです。
- 720p、1080p、4Kの画面で同じ大きさで表示。文字サイズは「中」と「大」の2種類。

## サイトが開かない場合：VPN

**お住まいの国やプロバイダーでサイトがブロックされている、または動画が読み込めない場合は、テレビ、セットトップボックス、またはルーターでVPNを有効にしてください。**

その前に、VPNの利用やこのようなコンテンツの閲覧が**お住まいの地域で合法であること**を確認してください。国によっては制限があります。現地の法律を守るのは利用者の義務です。本プロジェクトはVPNを提供せず、どのVPNサービスとも関係がなく、特定のサービスを推奨することもありません。

## プライバシー

- アプリにアカウントは一切不要です。Googleアカウントも、サイトのアカウントも必要ありません。
- Googleのサービスも、アプリ独自の分析ツールやカウンターもありません。本プロジェクトは独自のサーバーを持たず、作者はいかなるデータも受け取りません。
- 動画とサイトのページはディスクに保存されません。動画のサムネイルは、アプリの終了時と次回の起動時にもう一度削除されます。カテゴリ、チャンネル、モデル、投稿者の画像は、新しい画像に置き換えられるか、設定でキャッシュを消去するまで、キャッシュ（最大60 MB）に残ります。
- お気に入り、登録チャンネル、履歴、再生位置は端末内にのみ保存されます。
- PINコードはソルトとハッシュの形で保存されます。たまたま触れた人からは守れますが、端末に完全にアクセスできる人からは守れません。

**完全な匿名性はありません。** サイト、インターネットプロバイダー、ネットワーク管理者、VPNサービスは、それぞれの技術的な範囲内で、引き続き接続に関する情報を知ることができます。サイトは独自の規則に従ってリクエストを処理します。

### バックアップ

- エクスポートすると、「ダウンロード」フォルダーに `user_preferences_26_11_2026_02_49.dat` のようなファイルが作成されます。
- お気に入り、登録チャンネル、視聴履歴、動画の再生位置が含まれます。PINコードとアプリの設定は含まれません。
- バックアップの内容は圧縮・暗号化されているため、テキストエディターでは読めません。ただし、鍵はアプリに組み込まれており、ソースコードで確認できます。
- インポートは足りないものを追加するだけで、何も削除しません。履歴に保存されるのは最大100件です。
- このファイルは、キャッシュの消去やアプリのアンインストールでは消えません。不要になったらご自身で削除してください。

## インストール

Android 7.0以降が必要です。

1. このリポジトリの **Releases** からAPKをダウンロードします。
2. 使いやすい方法でAPKをテレビに転送します。たとえば、スマートフォンのLocalSendアプリや、パソコンからのSAMBAを利用できます。提供元不明のアプリのインストールを許可してから、インストールしてください。

ADBでインストールすることもできます（スマートフォンのatvTools、またはパソコンのADB App Control）。

このリポジトリのAPKか、ご自身でビルドしたAPKだけをインストールしてください。第三者のビルドについて作者は責任を負いません。

## ソースからのビルド

JDK 17以降とAndroid SDK（compileSdk 36）が必要です。SDKの場所は `local.properties` または環境変数 `ANDROID_HOME` で指定します。

```bash
./gradlew testDebugUnitTest
./gradlew assembleRelease
```

Windowsでは `.\gradlew.bat` を使います。出力ファイルは `app/build/outputs/apk/release/app-release.apk` です。

設定をしない場合、リリース版はお使いのパソコンの**デバッグ鍵**で署名されます。配布する場合は、自分の鍵（`keytool`）を作成し、同じ場所に `keystore.properties` ファイルを置いてください。

```properties
storeFile=release.p12
storePassword=あなたのパスワード
keyAlias=あなたのエイリアス
keyPassword=あなたのパスワード
```

`storeFile` のパスは、このファイルがあるフォルダーを基準にします。`keystore.properties` 自体のパスは、`local.properties`（`privatetube.signing=...`）または環境変数 `PRIVATETUBE_SIGNING` で指定します。鍵はリポジトリの外で保管し、バックアップを取ってください。署名の異なるAPKは以前のものに上書きインストールできません。古いバージョンを削除する前にエクスポートしてください。

## 構成

| `app/src/main/java/com/privatetube/app/` 内のフォルダー | 内容 |
|---|---|
| `core/network` | サイトへのリクエスト、アドレス、User-Agent |
| `core/parsing` | ページの解析。セレクターは `ParsingRules.kt` にまとめています |
| `data` | リポジトリ、端末内の保存、キャッシュ、バックアップ |
| `domain` | データモデル |
| `feature` | 各画面 |
| `ui` | 共通部品、フォーカス、画像の読み込み |

サイトのページ構造が変わった場合は、ほとんどの場合 `core/parsing` の修正で対応できます。`app/src/test/resources/fixtures/` のテスト用ページは匿名化されています。実際のサイトでの確認（`LiveSiteCheck`）は、変数 `TV_LIVE=1` を指定して手動でのみ実行します。

## 既知の制限

- アプリはサイトのページ構造と規則に依存しているため、**いつでも動かなくなる可能性があります**。
- サイトのアカウントにはログインできません。登録チャンネルとお気に入りは端末内のみで、サイトとは同期しません。新着動画の通知もありません。
- 有料コンテンツは再生できません。
- 地域によっては視聴できない動画があります。サイトがリクエストの頻度を制限することがあります。
- 翻訳はネイティブスピーカーの確認を受けていません。
- 開発中の確認は、テストとエミュレーター（画面が1080pのスマートフォン向けAndroidイメージ）で行いました。特定のテレビやセットトップボックスでの動作は保証しません。
